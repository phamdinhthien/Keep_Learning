Tải trước khi người dùng hover

Từ lúc con trỏ chạm vào nút tới lúc click thường mất vài trăm mili-giây. Dùng khoảng đó để bắt đầu tải thứ sắp cần.

Bài gốc: “Preloading network dependencies on hover” ↗
00 · Ý TƯỞNG

Hover là lời báo trước của người dùng

Sự kiện mouseover là tín hiệu khá rõ người dùng sắp làm gì. Ý tưởng: bắt đầu tải các tài nguyên cần cho hành động đó ngay khi hover, để lúc click thì request đã chạy được một đoạn, thậm chí xong rồi. Nên nắm event loop (bài 01) và biết sơ qua profiler.

01 · KHI NÀO DÙNG

Mọi kịch bản quan trọng nằm sau một cú click và cần tài nguyên từ xa

SPA

Chuyển route, mở modal, thao tác tương tác… thường cần thêm JSON, JS, CSS. Thông thường chúng chỉ được yêu cầu sau khi click.

Site HTML tĩnh

Trang kiểu Wikipedia điều hướng bằng thẻ <a>; trang đích chỉ được tải sau khi click link.

▣Ảnh/ví dụ gốc sơ đồ tải tài nguyên sau khi click trong SPA và site tĩnh↗
02 · TRƯỚC KHI TỐI ƯU

Click rồi mới tải

const btn = document.querySelector('#show-reviews');
btn.addEventListener('click', async () => {
  const reviews = await fetch('/api/reviews?product=42').then(r => r.json());
  openReviewsDialog(reviews);
});

03 · ÁP DỤNG

Bắt đầu tải từ lúc hover, dùng lại promise khi click

let reviewsPromise = null;
function loadReviews() {
  // chỉ gửi một lần; lần sau trả lại đúng promise đó
  reviewsPromise ??= fetch('/api/reviews?product=42').then(r => r.json());
  return reviewsPromise;
}

btn.addEventListener('mouseover', loadReviews);         // desktop
btn.addEventListener('touchstart', loadReviews, { passive: true }); // mobile
btn.addEventListener('click', async () => {
  openReviewsDialog(await loadReviews());   // đã bay sẵn hoặc đã xong
});

04 · LOẠI TÀI NGUYÊN KHÁC

Không chỉ JSON

Điều hướng trang tĩnh: <link rel="prefetch">

document.querySelectorAll('a[href^="/"]').forEach((a) => {
  a.addEventListener('mouseover', () => {
    if (a.dataset.prefetched) return;
    a.dataset.prefetched = '1';
    const link = document.createElement('link');
    link.rel = 'prefetch';
    link.href = a.href;
    document.head.appendChild(link);
  }, { once: true });
});

Chunk code-split: import()

btn.addEventListener('mouseover', () => { import('./ReviewsDialog.js'); }, { once: true });
05 · CÂN NHẮC

Đừng tải trước quá tay

  • Nếu thấy prefetch quá hăng (người dùng lướt chuột qua hàng loạt nút), thêm ngưỡng thời gian hover, ví dụ chỉ tải khi con trỏ nằm yên trên nút khoảng 100 ms.
  • Theo dõi tải lên backend: mục tiêu là cải thiện tốc độ cảm nhận, không phải đổi bằng chi phí server quá lớn.
06 · KIỂM CHỨNG

So sánh trong profiler

Bài gốc có trang ví dụ với hai nút: một không preload, một có. Ghi trace cho từng nút:

  • Không preload: sau click, người dùng không thấy gì cho tới khi request xong.
  • Có preload, hover đủ lâu: request xong trước cả khi click; người dùng không phải chờ mạng.
  • Có preload, hover thoáng qua: request chưa xong khi click, nhưng đã được “chạy đà”, nên vẫn nhanh hơn.
▣Ảnh/ví dụ gốc ảnh ba trường hợp trong profiler và trang ví dụ↗
  • mouseover / touchstart → bắt đầu tải; click → dùng lại cùng promise.
  • Áp dụng cho JSON, trang HTML (prefetch) và chunk JS (import()).
  • Đo tác động bằng chỉ số thật của kịch bản (bài 12).
