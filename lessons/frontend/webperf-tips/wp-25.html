Ưu tiên function thay vì class để minify tốt hơn

Minifier không dám đổi tên method và thuộc tính trên this, cũng không tree-shake được method thừa. Hàm export riêng lẻ thì làm được cả hai.

Bài gốc: “Favor functions over classes for better minification” ↗
00 · BỐI CẢNH

Class tiện, nhưng có giá

Từ ES2015, JavaScript có cú pháp class, quen thuộc với lập trình hướng đối tượng, và Babel/TypeScript giúp dùng nó cả trên trình duyệt cũ. Trước khi viết thêm class, nên biết nó có thể làm phình resource size và transfer size (bài 15). Cần biết cơ bản về minify (bài 17).

01 · VÍ DỤ CLASS

Một class gọi API

// ProductApi.js
export class ProductApi {
  constructor(host) {
    this.host = host;
  }
  getProduct(id) {
    return fetch(`${this.host}/products/${id}`);
  }
  getReviews(id) {
    return fetch(`${this.host}/products/${id}/reviews`);
  }
}

// app.js
import { ProductApi } from './ProductApi.js';
const api = new ProductApi('https://api.shop.vn');
const p = await api.getProduct(42);

Qua minifier phổ biến như Terser, kết quả (đã format lại cho dễ đọc) gần như giữ nguyên:

class t {
  constructor(s) { this.host = s }
  getProduct(s) { return fetch(`${this.host}/products/${s}`) }
  getReviews(s) { return fetch(`${this.host}/products/${s}/reviews`) }
}

Chỉ có tên class và tham số được rút gọn.

02 · VẤN ĐỀ

Minifier chỉ làm điều chắc chắn an toàn

Minifier thông thường chỉ áp dụng biến đổi an toàn. Với class, nó không thể chắc rằng đổi tên sẽ không phá code ở đâu đó (ví dụ truy cập động api['getProduct']), nên:

  • Không mangle được thuộc tính trên this (như this.host).
  • Không mangle được tên method (getProduct, getReviews).
  • Không tree-shake được method thừa. Tree shaking làm ở cấp import/export; nó bỏ được cả class không dùng, nhưng không bỏ được từng method. getReviews không ai gọi vẫn nằm trong bundle.

Class nhiều method vì thế vừa minify kém vừa kéo theo code thừa.

03 · GIẢI PHÁP

Export từng function

// ProductApi.js
export function getProduct(host, id) {
  return fetch(`${host}/products/${id}`);
}
export function getReviews(host, id) {
  return fetch(`${host}/products/${id}/reviews`);
}

// app.js
import { getProduct } from './ProductApi.js';
const p = await getProduct('https://api.shop.vn', 42);

Sau minify, phần còn lại của file chỉ là:

function t(s,o){return fetch(`${s}/products/${o}`)}
  • getReviews không dùng bị tree-shake bỏ hẳn.
  • Tên hàm getProduct được rút thành t.
  • Tham số được rút thành s, o.
  • Không còn phép gán this.host không minify được.
04 · CLOSURE COMPILER

Còn một lựa chọn, nhưng nặng nề

Closure Compiler ở chế độ Advanced minify class mạnh tay hơn, đổi tên cả thuộc tính lẫn method. Đổi lại, phải tuân thủ các quy tắc viết code rất chặt và tốn công tích hợp. Theo kinh nghiệm của tác giả bài gốc, dùng export function đơn giản hơn nhiều mà kết quả tương đương.

  • Class: method và this.x giữ nguyên tên; method thừa không bị loại.
  • Function export: được tree-shake và mangle triệt để.
  • Khi viết module tiện ích, ưu tiên export function.
