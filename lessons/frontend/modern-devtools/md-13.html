01. Bối cảnh ghi chú bài 13

Soylent.com dùng webfont; trước khi font sẵn sàng, trình duyệt ẩn chữ để tránh cảnh đổi font giật mắt, nên headline xuất hiện muộn

Soylent.com tải một custom webfont cho một phần chữ. Trước khi webfont sẵn sàng, trình duyệt ẩn chữ để tránh trải nghiệm giật khi đổi từ font dự phòng sang webfont. Mục tiêu bài: cải thiện hiệu năng tải trang của Soylent.com bằng tính năng local override của DevTools.

Lưu ý: video bài này nằm trên YouTube và chưa chép lời được; nội dung dựa trên ghi chú khoá học.
02. Network screenshots ghi chú bài 13

Bật chụp screenshot trong Network panel: một phần chữ đã hiện nhưng headline chính chưa; inspect headline để xác nhận nó dùng webfont

Dùng tính năng screenshots trong Network panel để quan sát: một số chữ đã tải, nhưng headline chính thì chưa. Khi headline đã hiện, inspect nó và xem Styles pane để xác nhận đang dùng một webfont.

03. font-display: swap ghi chú bài 13

swap cho font face không có block period và swap period vô hạn: chưa tải xong thì hiện font dự phòng, tải xong thì thay vào

Một cải thiện tiềm năng là thuộc tính font-display, cụ thể font-display: swap;. Font swap period: nếu font face chưa tải, mọi phần tử dùng nó phải render bằng font dự phòng; nếu font tải xong trong giai đoạn này thì được dùng bình thường. swap cho font face không có block period và swap period vô hạn.

Khó khăn: phải thêm vào file CSS của Soylent, mà tác dụng của nó chỉ thấy trong lúc tải trang. Sửa trong DevTools rồi reload là mất thay đổi. Local overrides giải quyết điều này.

04. Local overrides ghi chú bài 13

Cmd/Ctrl + click font-family để sang Sources, pretty print, bật overrides, Save for overrides, thêm font-display: swap vào mọi @font-face của Apercu

  1. Cmd/Ctrl + click vào thuộc tính font-family trong Styles pane: DevTools chuyển sang Sources panel.
  2. Pretty print file CSS.
  3. Mở pane Overrides ở sidebar của Sources và bật local overrides.
  4. Chuột phải file CSS › Save for Overrides.
  5. Thêm font-display: swap; vào mọi khối font-face định nghĩa font Apercu.
  6. Lưu bằng Cmd / Ctrl + S, reload trang và chụp screenshot lại.

Kết quả: first paint giờ đã có chữ.

05. Kết luận ghi chú bài 13

Network screenshots cho thấy chữ hiện trễ; Local overrides nối tài nguyên từ xa với file local để thay đổi CSS tồn tại qua reload

Bài dùng tính năng screenshot của Network panel để thấy chữ dùng webfont hiển thị trễ. Sau đó dùng local overrides của Sources panel để map tài nguyên từ xa sang file trên máy, rồi thêm font-display vào các định nghĩa font-face, và thay đổi đó được giữ qua reload.
