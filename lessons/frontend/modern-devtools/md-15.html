01. Bối cảnh ghi chú bài 15

Trang chủ Dev Tips từng tải rất nhiều ảnh thumbnail ngay khi mở trang, không lazy load

Mục tiêu bài: cải thiện hiệu năng của Dev Tips bằng native image lazy loading. Trước đây trang chủ Dev Tips tải nhiều ảnh thumbnail ngay lúc tải trang, và các ảnh này không được lazy load: Network panel đầy request ảnh.

Lưu ý: video bài này nằm trên YouTube và chưa chép lời được; nội dung dựa trên ghi chú khoá học.

03. Local Overrides ghi chú bài 15

Bật Local Overrides trên site production, sửa HTML thêm loading="lazy", ghi Network để xác nhận chỉ ảnh trong hoặc gần viewport được tải

Quy trình với Local Overrides:

  1. Với một website production, bật Local Overrides.
  2. Override HTML để các thẻ <img> có thêm loading="lazy".
  3. Ghi Network profile của trang đã override để xác nhận chỉ ảnh trong hoặc rất gần viewport được tải.

Cách dùng Local Overrides:

  1. Mở pane Overrides trong Sources panel.
  2. Chọn Enable Local Overrides.
  3. Chọn một thư mục trên máy để DevTools lưu các thay đổi.
  4. Tìm tài nguyên cần sửa trong Page pane (vẫn trong Sources).
  5. Sửa và lưu bằng Cmd + S / Ctrl + S.
  6. Reload và thấy tài nguyên local được dùng thay cho tài nguyên từ xa.

04. Dùng web proxy ghi chú bài 15

Web proxy chặn request và trả về file khác, kể cả file trên desktop; chạy được mọi trình duyệt, sửa được request lẫn response, dùng được cho điện thoại

Có nhiều giải pháp web proxy cài trên máy để chặn request và trả về một tài nguyên khác hoàn toàn, ví dụ file nằm trên desktop. Kết quả giống Local Overrides, nhưng bản proxy dùng được với mọi trình duyệt và sửa được cả request lẫn response. Ví dụ là Charles Proxy: chặn được cả HTTP và HTTPS, và có thể trỏ điện thoại tới proxy cài trên máy, nên override qua proxy làm được cả trên điện thoại.

Local OverridesCó sẵn trong DevTools, nhanh, chỉ trong Chrome của bạn.
Web proxyMọi trình duyệt, cả điện thoại, sửa được request và response; phải cài đặt.
05. Kết luận ghi chú bài 15

Local Overrides là cách nhanh để map tài nguyên từ xa sang file local, dựng thử biến thể của website và profile để xác nhận nó hiệu quả

Local Overrides trong DevTools cho một cách nhanh, dễ để map tài nguyên từ xa sang tài nguyên local, nhờ đó prototype các biến thể của website và performance profile chúng để xác nhận chúng hoạt động.
